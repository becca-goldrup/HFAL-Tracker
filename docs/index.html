About this data

Each hospital is checked against 17 requirements drawn from New York's Hospital Financial Assistance Law, using the materials on its website: the financial assistance application, the plain language summary, and the full policy. Grades follow the Community Service Society of New York (CSS) rubric.

Items marked needs review could not be confirmed automatically and are waiting for a person to check them. While any remain, a hospital's grade is shown as a range (for example "B to D").

Notes and quotes from hospitals' documents appear as written in the original.

For the CSS team

Pick an AI check, settle what it couldn't confirm, and choose what the public tabs show. Making changes requires access to the project's GitHub repository.

Run a new check

Run a full check on GitHub ↗
  1. On the page that opens, select Run workflow, then the green Run workflow button.
  2. The check takes about 30 to 45 minutes. When it finishes, its results appear here in the staff tab (Review, Data health and What this check changed). The public tabs keep showing the published dataset until you publish the new check below.

A check also runs automatically on the 1st of every month. Avoid running two at once; the second can't save.

What the public tabs show

The Overview, Hospitals and Map tabs show one dataset for everyone. Preview a dataset first (only you see the preview), then publish it.

1Review flagged items

For each item, read why it was flagged and the quoted text, open the document if needed, and decide. A decision applies to every hospital that shares that financial assistance page. Your decisions are saved in this browser as you go. To correct an answer that wasn't flagged, open the website in the Data health tab and choose Edit.

2Send your decisions

  1. Select Submit to GitHub. A GitHub page opens with your decisions already filled in.
  2. On that page, select Submit new issue. (You need to be signed in to GitHub with access to this project.)
  3. Within a few minutes, the spreadsheet and this dashboard update, and GitHub replies on the issue with a summary.

How the AI reached each answer, and how much weight each one can bear. Every answer is either backed by a sentence the tool pulled from the hospital's own documents, accepted because nothing problematic was found, or sent to a person to check. Open a website and choose Edit to correct any answer.
