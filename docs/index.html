About this data

Each hospital is checked against 17 requirements drawn from New York's Hospital Financial Assistance Law, using the materials on its website: the financial assistance application, the plain language summary, and the full policy. Grades follow the Community Service Society of New York (CSS) rubric.

Items marked needs review could not be confirmed automatically and are waiting for a person to check them. While any remain, a hospital's grade is shown as a range (for example "B to D").

For the CSS team

Run a new compliance check, and settle the items the AI couldn't confirm on its own. Making changes requires access to the project's GitHub repository.

1Run a new check

Run a full check on GitHub ↗
  1. On the page that opens, select Run workflow, then the green Run workflow button.
  2. The check takes about 30 to 45 minutes. When it finishes, this dashboard updates on its own.

A check also runs automatically on the 1st of every month.

2Review flagged items

For each item, read why it was flagged and the quoted text, open the document if needed, and decide. A decision applies to every hospital that shares that financial assistance page. Your decisions are saved in this browser as you go. To correct an answer that wasn't flagged, open the website in the Data health tab and choose Edit.

3Send your decisions

Open the GitHub upload page ↗
  1. Download the decisions file.
  2. Open the GitHub upload page, drag the file in, and select Commit changes.
  3. Within a few minutes, the spreadsheet and this dashboard update with your decisions.
